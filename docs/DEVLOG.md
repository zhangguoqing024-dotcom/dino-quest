# 开发日志

记录每一次和孩子一起推进项目的过程 —— 想法、决策、翻车、突破。

## 2026-08-29 · Day 1 立项

- 想法起源：希望把孩子在家做家务、学习的动力，和一款他们真正想玩的游戏挂钩。
- 确定核心玩法：任务 → 积分 → 商城 → 养恐龙。
- 家庭成员：爸爸、妈妈、哥哥、妹妹，各有一只专属恐龙。
- 决定先不定技术栈，先把设计文档和项目骨架搭起来。
- 建立 GitHub 公开仓库，把整个创造过程记录下来。

## 2026-09-05 · Day 2 从设计到可玩原型

一天之内从"只有 GDD 文档"推进到"iPad 上能玩的 PWA"。

**设计决策**
- 恐龙：不做官方图库，全部由玩家用 AIGC 生成，且需要生成多个成长阶段的外观图。
- 任务：**线下运作 + 每周家庭会议对齐 + iPad 只做每周结算录入**。iPad 不承担任务发布/确认流程 —— 避免"家庭教育变成打卡 App"。
- 结算日：每周日晚上开会后录入积分。漏录不支持补录。
- 技术栈：**React + Vite PWA**，本地 localStorage 存储。以后玩法稳定再评估是否 SwiftUI 重写。
- 恐龙阶段：先做 3 个，聊完升到 **5 个**（幼年 / 少年 / 青年 / 成年 / 究极），每阶段约 1 个月，总共半年养到究极。
- 商城定价：每周 25 分预算，价格向大陆超市看齐（青草 1 分 ~ 王冠 200 分）。

**做出来的东西**
- **家庭大厅**（首屏）：全家总积分、排行榜、每人恐龙迷你状态条。
- **恐龙主页**：
  - 顶部横向滑动的 5 阶段成长时间线（未解锁置灰🔒、当前高亮、每张卡显示停留时长和吃过什么）
  - "下一目标"面板：还差多少经验、约几份鲜肉
  - 恐龙大图 + 名字（可编辑）
  - 身高 / 体重 / 力量 / 攻击（阶段内线性成长）
  - 饱食度/口渴度/心情三条状态条
  - 喂养面板（快速从仓库喂）
- **积分**：每周积分录入 + 历史记录 + 可删除
- **商城**：4 大类物品，购买带确认弹窗
- **仓库**：物品分类展示，使用/装备都带确认弹窗
- **自然衰减**：每天 −25/−30/−12，低于 30 触发三重照顾提醒（tab 红点 + 胶囊红点 + 顶部警示条）
- **升阶庆祝**：喂养触发升阶时弹撒花恭喜弹窗
- **PWA**：manifest + 图标，加到 iPad 主屏幕全屏运行

**技术上**
- 单文件 store（useSyncExternalStore + localStorage），零依赖状态管理
- ConfirmModal 抽成共用组件
- 数据 migrate 机制：老存档自动补齐新字段（stageImages / stageHistory / lastTickAt）
