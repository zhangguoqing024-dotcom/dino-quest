# 游戏设计文档 (Game Design Document)

> 版本：v0.1 · 更新日期：2026-08-29

## 1. 概述

### 1.1 游戏名称
**恐龙养成记**（暂定，英文名 Dino Quest）

### 1.2 一句话简介
把现实中的家务和学习任务，变成孩子培养专属恐龙的燃料。

### 1.3 目标平台
iPad（未来可能扩展到 iPhone / Web）

### 1.4 目标玩家
- 主要：家中的孩子（哥哥、妹妹）
- 次要：父母（爸爸、妈妈），承担任务发布者与见证者的角色

### 1.5 游戏类型
养成 + 轻度 RPG + 家庭协作

## 2. 核心循环

```
现实任务  →  获得积分  →  商城消费  →  喂养/装扮恐龙  →  恐龙成长  →  解锁新任务/新挑战
   ↑                                                                          ↓
   └──────────────────────────  持续激励  ──────────────────────────────────┘
```

## 3. 角色系统

### 3.1 玩家角色
四位家庭成员，每人拥有：
- 一只专属恐龙
- 独立的积分账户
- 独立的仓库（食物、水、武器）

### 3.2 恐龙
- **属性**：等级、体型、生命值、攻击力、饱食度、口渴度、心情
- **成长**：通过喂食、喂水提升；等级越高，外观进化越明显
- **装扮**：武器影响攻击力，装饰影响心情/外观

## 4. 系统设计

### 4.1 任务系统
| 字段 | 说明 |
|------|------|
| 任务名称 | 例如"整理书桌" |
| 发布者 | 爸爸 / 妈妈 |
| 承担者 | 哥哥 / 妹妹（或任意成员） |
| 积分奖励 | 例如 10 分 |
| 频次 | 一次性 / 每日 / 每周 |
| 确认机制 | 承担者标记完成 → 发布者确认 → 积分到账 |

### 4.2 积分商城
- **食物**：便宜的青草、贵一些的肉类、稀有的能量果
- **水**：普通水、矿泉水、魔法泉水
- **武器**：木棒、石斧、铁剑、传说武器
- **装饰**：帽子、披风、翅膀

### 4.3 恐龙养成
- 饱食度、口渴度会随时间下降，需要定期喂养
- 达到成长阈值时，恐龙升级，外观发生阶段性变化
- 装备武器后，可参加家庭对战 / PVE 挑战（远期功能）

### 4.4 家庭互动（远期）
- 成员之间可以赠送物资
- 兄妹恐龙可切磋、组队
- 家庭排行榜、周报

## 6. 数据模型（草案）

```
User { id, name, role(parent/child), points, avatar }
Task { id, title, publisher, assignee, reward, status, frequency }
Item { id, type(food/water/weapon/decor), name, price, effect }
Inventory { userId, itemId, quantity }
Dino { id, ownerId, level, hp, atk, hunger, thirst, mood, equipped[] }
```

## 7. 非功能需求

- **家长控制**：积分发放必须由父母确认，避免孩子自己刷分
- **防沉迷**：每日游戏时长限制（可由父母设置）
- **离线可用**：核心玩法不依赖网络
- **数据安全**：家庭数据本地存储优先，云同步可选
