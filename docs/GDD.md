# 游戏设计文档 (Game Design Document)

> 版本：v0.3 · 更新日期：2026-09-05

## 1. 概述

### 1.1 游戏名称
**恐龙养成记**（暂定，英文名 Dino Quest）

### 1.2 一句话简介
把现实中的家务和学习任务，变成孩子培养专属恐龙的燃料。

### 1.3 目标平台
iPad（未来可能扩展到 iPhone / Web）

### 1.4 目标玩家
- 主要：家中的孩子（哥哥、妹妹）
- 次要：父母（爸爸、妈妈），承担任务发布者与见证者的角色

### 1.5 游戏类型
养成 + 轻度 RPG + 家庭协作

## 2. 核心循环

```
现实任务  →  获得积分  →  商城消费  →  喂养/装扮恐龙  →  恐龙成长  →  解锁新任务/新挑战
   ↑                                                                          ↓
   └──────────────────────────  持续激励  ──────────────────────────────────┘
```

## 3. 角色系统

### 3.1 玩家角色
四位家庭成员，每人拥有：
- 一只专属恐龙
- 独立的积分账户
- 独立的仓库（食物、水、武器）

### 3.2 恐龙
- **来源**：每个家庭成员由自己使用 AIGC 工具生成一只专属恐龙，包含 5 个成长阶段的外观图。
- **成长阶段**：幼年 / 少年 / 青年 / 成年 / 究极。累计经验门槛：0 / 500 / 1100 / 1800 / 2700。每阶段约 1 个月，总共约半年养到究极。
- **成长属性**（阶段内随经验线性成长）：

| 阶段 | 身高 | 体重 | 力量 |
|---|---|---|---|
| 幼年 | 50 cm | 20 kg | 5 |
| 少年 | 120 cm | 80 kg | 15 |
| 青年 | 220 cm | 300 kg | 40 |
| 成年 | 350 cm | 800 kg | 80 |
| 究极 | 500 cm | 2 吨 | 150 |

- **状态**：饱食度 / 口渴度 / 心情（0-100），随时间自然衰减：每 24 小时 −25 / −30 / −12。任一低于 30 触发"需要照顾"提醒。
- **攻击**：力量（阶段成长）+ 武器加成。
- **装扮**：武器/装饰一次购买永久保留，可替换。

## 4. 系统设计

### 4.1 任务系统（线下打分 + 每周结算入账）

任务的**执行与打分完全在线下**进行，iPad 只承担"总账户"的角色。

**流程**：
1. **线下**：家里每人有自己的实体计分板（白板 / 打印表 / 贴纸墙），本周做完哪些任务、得多少分，自己（在父母见证下）记录到计分板上。
2. **每周家庭会议**：全家一起开会，逐人对齐本周的任务完成情况和最终积分。
3. **录入 iPad**：会议对齐后的本周积分，由父母录入到 iPad 中，累计到每人的总积分账户，用于商城消费。

**iPad 端需要的能力**：
- 每人一个积分账户，支持**按周录入**一笔积分（附本周备注/日期）
- 展示每人的积分历史（按周）
- 商城扣分

**iPad 端 _不_ 需要**（至少 MVP 阶段）：
- 任务发布、任务领取、任务确认按钮 —— 这些都在线下完成
- 逐条任务的记录 —— 只记周汇总

### 4.2 积分商城

**定价前提**：每人约 25 分/周 ≈ 100 分/月。基础吃喝走"每天 1-2 分能撑住"的路线，武器/装饰走"数周攒一件"的长期目标路线。价格感参考大陆超市（青菜几毛、矿泉水 2 元、玩具剑几十、金饰上百）。

#### 🍖 食物（消耗品，恢复饱食度）
| 物品 | 价格 | 效果 | 现实类比 |
|---|---|---|---|
| 青草 | 1 分 | 饱食 +10 | 一把小青菜 |
| 野果 | 2 分 | 饱食 +18 | 一个苹果 |
| 鲜肉 | 5 分 | 饱食 +35 | 一份鸡腿 |
| 能量果 | 12 分 | 饱食 +60，心情 +5 | 稀有水果礼盒 |
| ⭐ 龙涎果 | 30 分 | 满饱食度 + 心情满 | 珍藏级 |

#### 💧 水（消耗品，恢复口渴度）
| 物品 | 价格 | 效果 | 现实类比 |
|---|---|---|---|
| 河水 | 1 分 | 口渴 +12 | 白开水 |
| 山泉水 | 3 分 | 口渴 +30 | 农夫山泉 |
| ⭐ 魔法泉水 | 10 分 | 口渴满 + 心情 +3 | 高端矿泉水 |

#### ⚔️ 武器（一次购买，永久装备，可替换）
| 物品 | 价格 | 效果 |
|---|---|---|
| 木棒 | 15 分 | 攻击 +2 |
| 石斧 | 40 分 | 攻击 +5 |
| 铁剑 | 100 分 | 攻击 +12 |
| ⭐ 龙牙剑 | 300 分 | 攻击 +30，特效 |

#### 👑 装饰（一次购买，永久，可换）
| 物品 | 价格 | 效果 |
|---|---|---|
| 花环 | 8 分 | 心情 +2 |
| 侦察帽 | 15 分 | 心情 +3 |
| 英雄披风 | 25 分 | 心情 +5 |
| 天使之翼 | 80 分 | 心情 +10，外观特效 |
| ⭐ 王冠 | 200 分 | 心情 +15，家庭榜光环 |

**节奏预期**：每周 25 分 → 约 20 分买吃喝 → 5 分/周攒长期目标 → 3 周一把石斧 / 5 周一件披风 / 20 周一把铁剑。

### 4.3 恐龙养成
- 饱食度、口渴度会随时间下降，需要定期喂养
- 达到成长阈值时，恐龙升级，外观发生阶段性变化
- 装备武器后，可参加家庭对战 / PVE 挑战（远期功能）

### 4.4 家庭互动（远期）
- 成员之间可以赠送物资
- 兄妹恐龙可切磋、组队
- 家庭排行榜、周报

## 6. 数据模型（草案）

```
User        { id, name, role(parent/child), totalPoints, avatar }
WeeklyEntry { id, userId, weekOf(YYYY-MM-DD 周一), points, note, enteredBy, enteredAt }
Item        { id, type(food/water/weapon/decor), name, price, effect }
Inventory   { userId, itemId, quantity }
Dino        { id, ownerId, level, hp, atk, hunger, thirst, mood, equipped[], stageImages[] }
DinoStage   { dinoId, stageIndex, unlockLevel, imageUrl }   # AIGC 生成的各阶段外观
```

> 注：不再有 Task 实体 —— 任务在线下用实体计分板管理，iPad 只保存每周结算入账（WeeklyEntry）。

## 7. 非功能需求

- **家长控制**：积分发放必须由父母确认，避免孩子自己刷分
- **防沉迷**：每日游戏时长限制（可由父母设置）
- **离线可用**：核心玩法不依赖网络
- **数据安全**：家庭数据本地存储优先，云同步可选

## 9. v0.2 关键决策记录（2026-09-05）

- **恐龙来源**：不做官方图库，全部由玩家用 AIGC 自己生成（含各成长阶段）。
- **恐龙阶段**：~~3 个阶段~~ → **5 个阶段**（幼年 / 少年 / 青年 / 成年 / 究极），每阶段 ~1 个月。
- **AIGC 图导入**：iPad 相册直接选（不做云端上传流程）。
- **任务系统**：线下运作 + 每周家庭会议对齐 + iPad 只录入每周积分总数。iPad 不承担任务发布/确认流程。
- **结算日**：每周日晚上开家庭会议 → 录入 iPad。漏录的周暂不支持补录（后续再改）。
- **积分预期**：每人每周约 20–30 分，商城定价按此校准（详见 §4.2）。
- **技术栈**：**React + Vite，PWA 加到 iPad 主屏幕**。先做 Web 原型/MVP，等玩法稳定后再评估要不要 SwiftUI 重写。数据本地存储（IndexedDB）优先。
